# mdellavo/homebrew-tap

Homebrew formulae for [mdellavo](https://github.com/mdellavo)'s tools.

```sh
brew install mdellavo/tap/markdown-viewer
```

Or tap once, then install by name:

```sh
brew tap mdellavo/tap
brew install markdown-viewer
```

## Formulae

| Formula | Description |
|---|---|
| [markdown-viewer](https://github.com/mdellavo/markdown-viewer) | Render Markdown with GitHub styling and live-reload it in your browser |

Formulae are updated by each project's release workflow. Prebuilt binaries
are provided for macOS (Apple Silicon and Intel) and Linux (x86_64 and
ARM64); `brew install --HEAD` builds from source.
